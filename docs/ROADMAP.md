# Tavern Dice 后续方向

产品范围聚焦于当前场景战斗：生成或读取场面、结构化参战数据、选择行动、本地掷骰、保存进度与主动发送结算。本文列出后续改进方向，不代表发布日期或已经完成的验收。

## 近期优先项

- 场景生成的取消、超时、重复点击与生成完成事件兼容。
- 聊天切换时停止自动推进，隔离未完成的模型请求并恢复正确存档。
- 复杂场景的玩家识别、阵营、临时状态与技能提取质量。
- 战斗决策的合法目标校验、资源限制与失败回退。
- 战斗存档导入导出、旧配置兼容与恢复后状态一致性。
- 结果预览、长度控制与发送反馈。

## 验证与兼容

- 扩充确定性结算、快照恢复和行动边界测试。
- 覆盖模型请求失败、场景解析失败与取消后的界面恢复。
- 在 SillyTavern 与 TauriTavern 中检查启动、嵌入面板、悬浮球和斜杠命令。
- 在移动端与不同主题下检查战斗信息的可读性和操作空间。

## 可选方向

- 更清晰的行动时间线、伤害统计与战斗复盘。
- 多方阵营和复杂技能的交互改进。
- 本地化与可访问性。

新功能应围绕当前战斗闭环设计，并同时更新使用文档、提示词说明和必要测试。参见[架构设计](ARCHITECTURE.md)、[提示词设计](PROMPTS.md)与[使用说明](../README.md)。
